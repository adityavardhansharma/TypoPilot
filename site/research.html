Current recommendation

A small contextual model, tuned to correct, not rewrite.

The selected runtime is a fine-tuned Llama 3.2 1B model merged and quantised to GGUF Q4_K_M. Fine-tuning was essential: the untuned base model produced zero clean correction-only outputs across the eight manual cases.

Model history

What we trained, and what each experiment taught us.

Baseline

Identity, rules, SymSpell

Established the “do nothing” floor and exposed the cost of dictionary-only correction. SymSpell changed 44% of cases incorrectly in the early suite.

Byte-level pilot

ByT5-small

The first pilot halved CER from 10.1% to 5.0% and reached 43.8% exact match, proving the signal was learnable. Later versions improved spelling but still missed contextual grammar.

Contextual shift

Llama 3.2 1B + LoRA

A compact language model learned correction-only behaviour while using sentence context. The untuned base comparison demonstrated that the gain came from fine-tuning, not prompting alone.

Deployment pass

F16 → Q8 → Q4_K_M

Q4_K_M reduced model size by 67% versus F16 and produced the same eight clean outputs as Q8 in the manual test, at the lowest measured sentence latency.

Three views of quality, kept separate.

Published comparison

Competitive evidence, without inventing a shared leaderboard.

On its own spelling suite, TypoPilot’s 95.70% word-accuracy proxy is numerically above systems reported by the LREC 2020 comparison. The datasets and scorers differ, so TypoPilot remains officially unranked until it runs on the paper’s exact test inputs.

Limitations

What still breaks, and what we should train next.

Real-world C4 errors

Exact match falls to 10.67% and overcorrection rises to 31.33%. These examples differ sharply from the synthetic training distribution.

Extreme segmentation

The public split/concatenation sample reaches only 50.14% exact, showing that letter-by-letter splits and merged spans need dedicated training.

Grammar is intentionally conservative

The model was optimized primarily for spelling and minimal edits. It may preserve awkward grammar rather than rewrite professional or personal voice.

English first

The original vision includes Hinglish, but the current recommended model and reported results are English-focused. Hinglish should not be implied as complete.

No official Apple/Gboard comparison

Neither exposes a reproducible public API and absolute shared-dataset results are unavailable. Individual examples are useful demonstrations, not a universal ranking.

CPU performance varies

All reported native timings use one Ryzen 9 4900HS laptop. Sentence length, thread count, instruction set, and thermal state affect latency.

Methodology

How to read the numbers.

Exact match
The model output must equal the reference character for character, including capitalization and punctuation.
CER
Character edit distance divided by reference length. Lower is better.
WER
Word-token edit distance divided by reference token count. Lower is better.
Overcorrection
The output changed the input but ended farther from the reference than doing nothing.
Native timing
The model is loaded once, retained in memory, and receives a TSV batch through the C++ harness. Reported per-example latency excludes model load.
Cross-system ranking
Only systems evaluated on identical inputs with the same scorer should share an official position.
